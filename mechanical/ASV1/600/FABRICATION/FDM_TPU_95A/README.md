# Left shoe sole — module 600

| Specification | Value |
|---|---|
| Part | [ASV1_600_40D.STL](ASV1_600_40D.STL) |
| Manufacturing process | FDM 3D printing |
| Material | TPU, Shore 95A |
| Quantity | 1 for the left foot; 2 soles per robot |

The same sole fits either foot. The [right shoe sole (module 500)](../../../500/FABRICATION/FDM_TPU_95A/README.md) contains identical geometry under the right-leg part filename. Print two copies of this geometry: one for each foot.

## Print settings

| Setting | Value |
|---|---|
| STL units | Millimetres |
| Print scale | 100% |
| Orientation | Sole facing down, on the print bed |
| Layer height | 0.2 mm |
| Wall count | 4 |
| Top layers | 2 |
| Bottom layers | 2 |
| Infill | 15%, grid pattern |
| Supports | None required |

## Attachment and compatibility

Slip the foot into the shoe, then secure it to the foot with **two M4 × 16 mm flat-head bolts**: one at the toe and one at the heel. No adhesive is required. Both feet together require **four bolts**.

Compatibility is confirmed for the latest foot design in this repository as of 2026-11-04.
