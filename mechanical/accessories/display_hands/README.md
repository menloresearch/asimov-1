# Asimov 1 Display Hands

Fists for Asimov 1, for display only. They don't grip. The DIY kit ships without hands, and these cover the open wrists until you mount a gripper or a hand of your own.

[ASV1_DUMMY_HANDS.3mf](ASV1_DUMMY_HANDS.3mf) is the supplied print-ready Bambu Studio project for the Display Hands. It contains the models, plate layout, and printer, filament, and print settings. Internally we call them the dummy hands, so the project file keeps its `ASV1_DUMMY_HANDS` name.

## Printing

1. Download the complete `.3mf` file with its Git LFS content.
2. Open it in **Bambu Studio as a project** to load the embedded settings and plate layout.
3. Use the saved project settings to slice and print the hands. The supplied project uses a **Bambu Lab P1S with a 0.4 mm nozzle** and **PLA** filament settings.
